# Краткое описание архитектуры

Лабораторная работа выполнена по шаблону **MVVM**:
* **Model** — данные и сущности предметной области (Hotel, Room, Customer, Booking).
* **View** — экраны и пользовательский интерфейс. Не содержат логики расчетов.
* **ViewModel** — логика для каждого экрана, обработка ввода и вызовы репозиториев.
